# Highway Greens Website

A premium, highly interactive, and fully responsive landing page for the **Highway Greens** residential project. Built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion** for a luxurious visual identity and smooth experience.

---

## ✨ Features

- 🌲 **Luxurious Visual Design**: A curated color palette of deep greens and gold/amber accents reflecting high-end nature-centric residential estates.
- 📱 **Fully Responsive Layouts**: Crafted for flawless presentation across mobile, tablet, and desktop viewports.
- 🗺️ **Interactive OpenStreetMap Section**: Embedded maps displaying proximity to schools, expressways, and healthcare services with dynamic text layouts.
- ⚡ **Seamless Animations**: Utilizing Framer Motion for premium fade-ins, sliding panels, hover effects, and interactive form feedback.
- 📝 **Contact / Inquiry Form**: A custom validation-ready form suited for residential and commercial inquiry gathering.
- 🔀 **Custom 404 Error Page**: Matching brand aesthetics and allowing smooth navigation back to the primary landing page.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js (App Router)](https://nextjs.org/)
- **Library**: [React](https://react.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Fonts**: [Google Fonts (Outfit)](https://fonts.google.com/specimen/Outfit)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18.x or above recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ritzdevelopers/highway-greens-website.git
   cd highway-greens-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Start production server:**
   ```bash
   npm start
   ```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.
